# 🤖 Telegram System Control Bot

Con bot Telegram viết bằng Python giúp điều khiển và thực thi các câu lệnh hệ thống trực tiếp từ xa thông qua `subprocess`.

## 🚀 Tính năng chính
* Gửi lệnh CMD trực tiếp từ điện thoại qua Telegram.
* Nhận kết quả phản hồi nhanh chóng.
* Có tính năng bảo mật (chỉ cho phép chủ nhân ra lệnh).

## 🛠️ Công nghệ sử dụng
* **Python 3.x**
* Thư viện `python-telegram-bot`
* Thư viện chuẩn `subprocess`
